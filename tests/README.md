# Expense Tracker API

A backend REST API for managing personal expenses.

## Technologies

- Node.js
- Express.js
- MongoDB
- Mongoose
- dotenv
- Vitest
- Supertest

## Installation

Clone the repository and install dependencies:

```bash
npm install
```

Create a `.env` file using `.env.example` and configure your environment variables.

## Run the server

```bash
npm start
```

## Run tests

```bash
npm test
```

## Health Check

```http
GET /health
```

## Main Features

- Expense creation
- Expense validation
- MongoDB integration
- Automated API testing

## Project Status

Backend skeleton completed. Authentication, full CRUD, ownership, search, and frontend features are planned for upcoming development stages.
